# Brainstormers – Tasktopia
## Personal To-Do List Application with Categories

### Project Overview
A Java-based task management application that helps all types of users organise and prioritise their daily tasks using a customisable categorising system. The application features a simple console interface with persistent storage to meet all users' needs. The application incorporates Natural Language Processing (NLP) to allow users to input tasks using everyday language, improving usability and efficiency. 

### Core Purpose
The core purpose of the application is to provide users with something intuitive and engaging that allows them to easily manage their personal and professional tasks. By combining urgency-based categorisation with natural language input, the system allows users to quickly capture unstructured “brain dumps” and automatically transform them into organised, prioritised tasks. Altogether, these features reduce the effort required to manually structure tasks and enable the system to automatically interpret, categorise, and prioritise them for improved productivity.

### Target Users
Our target users include:
- **Students** – specifically university students managing multiple assignments and deadlines
- **Professionals** – tracking multiple work tasks
- **Everyone** – anyone wanting to better organise their personal to-dos in a fun and engaging way

### Key Features (High-Level)
- Create, edit, and delete tasks
- Organise tasks into custom categories
- Mark tasks as complete/incomplete
- View tasks by category or due date
- Save/load tasks from file
- Use Natural Language Processing (NLP) to break down input into organised tasks

### Technology Stack
- **Language:** Java
- **Version Control:** Git/GitHub
- **AI Integration:** NLP processing via REST API (e.g. OpenAI, Google Gemini, etc.)
- **Tools:** IntelliJ for development, Discord for team communication
