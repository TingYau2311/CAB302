# Brainstormers – Tasktopia
## Personal To-Do List Application with Categories

### Project Overview
Our plan is to create a Java-based task management application that helps all types of users organise and prioritise their daily tasks using a customisable categorising system. The application features a simple console interface with persistent storage for all of the users' needs.

### Core Purpose
The core purpose of the application is to provide users with something intuitive and engaging that allows them to easily manage their personal and professional tasks by categorising them by urgency for better organisation and productivity.

### Target Users
Our target users include:
- **Students** – specifically university students managing multiple assignments and deadlines
- **Professionals** – tracking multiple work tasks
- **Everyone** – anyone wanting to better organise their personal to-dos in a fun and engaging way

### Key Features (High-Level)
- Create, edit, and delete tasks
- Organise tasks into custom categories
- Mark tasks as complete/incomplete
- View tasks by category or due date
- Save/load tasks from file

### Technology Stack
- **Language:** Java
- **Version Control:** Git/GitHub
- **Tools:** IntelliJ for development, Discord for team communication
